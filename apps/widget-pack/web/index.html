🧩 Widget Pack

Bộ widget custom để agent chèn vào ô chat qua emit_widget kind "app" (khám phá bằng tool widget_list). Mỗi widget là một trang tĩnh nhận tham số qua query string. Demo với tham số mẫu:

widget-pack.countdown — { to, label }

widget-pack.progress — { value, max, label }

widget-pack.table — { rows, cols, title }

widget-pack.chart — { data, type, title }

widget-pack.chart (pie)

widget-pack.image — { url, caption }

widget-pack.video — { url, poster, caption }
